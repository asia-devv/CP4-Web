# 📋 Gerenciador de Tarefas
#### Página desenvolvida em React para criação e gerenciamento de tarefas. Permitindo adicionar tarefas com título, descrição, data e prioridade, além de controlar o status de conclusão e filtrar as tarefas.

  </a>
</p>


## 🚀 Funcionalidades
* ➕ Adicionar novas tarefas
* 📝 Definir título e descrição
* 📅 Definir data de conclusão
* ✅ Marcar tarefas como concluídas
* 🔄 Alternar entre tarefas concluídas e pendentes
* 🗑️ Excluir tarefas
* ⚡ Definir nível de prioridade
* 🔎 Filtrar tarefas:
* 💾 Dados salvos automaticamente no `localStorage`

## ⚙️ Como executar o projeto
1. Clone o repositório:
```bash
git clone https://github.com/asia-devv/CP4-Web.git
```
2. Entre na pasta do projeto
```bash
cd CP4-Web
```
3. Intale as dependências
```bash
npm install
```
4. Execute o projeto
```bash
npm run dev
```
